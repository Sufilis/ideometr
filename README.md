# Тест на идеологию

Сайт с тестом на политические взгляды. Можно выбрать длину теста:

- **Экспресс**: 16 вопросов, быстрый ориентир
- **Стандарт**: 40 вопросов
- **Глубокий анализ**: 80 вопросов, самый точный результат

По итогам показываются идеология, её ответвление, известный человек и страна или период с такими взглядами. Отдельная страница объясняет каждую идеологию простыми словами.

Ответы считаются в браузере и никуда не отправляются.

## Запуск

Откройте `index.html` в браузере. Сервер не нужен.

## Структура

- `index.html`: разметка
- `style.css`: стили
- `data.js`: вопросы, идеологии, ответвления
- `app.js`: логика теста
- `ads.js`, `stats.js`: необязательные настройки рекламы и счётчика (по умолчанию выключены)

Тест упрощён и не претендует на научную точность.
